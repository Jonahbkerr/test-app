# Sempra Grammar & Syntax

## Root Logograms
- `GEN~` : Generate artifact/code
- `ARCH~` : Architecture blueprint
- `STATE~` : State machine definition
- `CORE!` : Core constraint / Iron Triangle
- `EXT~` : Extension module

## Vector Modifiers
- `!` : Critical, mandatory, or forced execution constraint
- `~` : Dynamic state, transition, or asynchronous process
- `+` : Positive modifier, addition, or increment
- `-` : Negative modifier, cost, penalty, or decrement
- `:` : Sub-allocation, scoping, or assignment
- `>` : Flow direction, transformation, or pipeline step
